```sql
ATTACH 'ducklake:moraine:s3://bucket/prefix' AS lake
  (DATA_PATH 's3://bucket/prefix-data/',
   META_DATA_PATH 's3://bucket/prefix-data/', READ_WRITE);

CREATE TABLE lake.events (id BIGINT, payload VARCHAR);
INSERT INTO lake.events VALUES (1, 'hello, bucket');
```

DuckLake keeps table data in object storage and its catalog in a SQL
database. Moraine replaces that database with [SlateDB](https://slatedb.io),
a key-value store whose state also lives in object storage. The catalog
sits in the bucket next to the Parquet files, so there is no catalog server
to run, and copying the bucket copies the whole lake.

- The [overview](guide/overview/) explains what moraine is and what it costs.
- [Getting started](guide/getting-started/) installs the extension and attaches a lake.
- [Configuration](guide/configuration/) lists every attach option and function.
- The [design documents](rfcs/) record how it works.
